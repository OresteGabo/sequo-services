# Public SEQUO website — content and capability review

Read-only local-source audit, 2026-11-09. Website baseline HEAD 76dc615; API inspected HEAD 98e391b. No public-network, deployment, provider, device, build or business-data action was performed. No private configuration, invoice or signed-party contact details were inspected. The current App.vue/AI_CONTEXT describe a product narrative, not evidence that a public production service or mailbox is available.

## Immediate copy decisions

- Use the user's target **www.sequoservice.com**. All four apps name **api.sequoservice.com** as their production API origin. The website notes' plural sequoservices.com/api.sequoservices.com conflict with those sources and are stale; no DNS/domain ownership check was performed.
- Public brand: **SEQUO**. Product roles: clients, commerçants, livreurs, partenaires de points relais; apps SEQUO, SEQUO Vendor, SEQUO Rider, SEQUO Hub. Do not present the staff admin portal as the customer web app or expose admin/local-fixture access.
- Lomé/Togo is supported as the intended market by app copy, Africa/Lome scheduling and Togo-specific provider identifiers. Prefer **« Pensé pour le commerce local à Lomé, au Togo »**. This does not prove launch coverage, active partner counts, all-city availability or delivery zones.
- **The owner approved `hello@sequoservices.com` during this task** (2026-11-09) and will update it manually if needed. It is centralized in `src/content/site.ts`. Mailbox deliverability was not tested. No public telephone, street address or store listing was established; none is invented.
- Previous “Download for Android” opens email, not a store/download. Previous decorative QR encodes no verified app link. Remove those download/scan promises until real approved destinations exist. No lead capture backend exists in the inspected website; no fake successful signup.

## Ready-to-use positioning

« Le commerce local, mieux coordonné. SEQUO prépare une expérience qui relie les clients, les commerçants, les livreurs et les points relais. Découvrez comment les commandes, leur préparation et les remises peuvent être suivies dans un même parcours. »

Suitable discovery CTAs while app-store distribution is unconfirmed: « Découvrir le parcours », « Pour les commerçants », « Pour les livreurs », « Comprendre les points relais ». Keep preview art explicitly illustrative. Avoid invented testimonials, partner logos, active-user/site counts, certifications, delivery guarantees or claims that unconfigured payment/benefit features are live.

## Implemented website corrections

The redesigned French page replaces the old blue Hub-first placeholder layout with the existing SEQUO emerald brand, an original labelled commerce illustration, a labelled interactive customer-journey illustration, four role panels and native FAQ disclosures. There are no fake metrics, app-store badges, download QR codes, testimonials, claim of working Hub camera scanning or automated connected lockers. Contact opens the owner-approved mailbox, with explicit role-specific subjects.

Public launch preparation is stated beside the hero CTA, in the access FAQ and near the contact section. Provider payments/refunds/payouts and subscription/referral availability are explicitly distinguished from implemented order/status workflows. The 72-hour wording is for eligible return requests after delivery; personal relay collection codes and relay category exclusions are explained without publishing internal credentials or private identifiers.

No production, provider, native-app or financial operation was run for this content review. Local website browser/build verification is recorded separately in `PUBLIC_SITE_REDESIGN_2026-11-09.md`.
